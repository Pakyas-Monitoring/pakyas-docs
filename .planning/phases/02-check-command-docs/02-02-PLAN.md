   - description: "Generate shell completion scripts"

2. Introduction paragraph explaining completion generates tab-completion scripts for various shells

3. Sections:
   - ## Usage
     ```bash
     pakyas completion <SHELL>
     ```

   - ## Arguments table:
     | Argument | Description |
     |----------|-------------|
     | `SHELL` | Shell to generate completions for: bash, zsh, fish, powershell, elvish |

   - ## Installation by Shell - separate H3 sections for each shell:

   ### Bash
   ```bash
   pakyas completion bash > ~/.local/share/bash-completion/completions/pakyas
   # Restart shell or source the file
   source ~/.local/share/bash-completion/completions/pakyas
   ```

   ### Zsh
   ```bash
   # Ensure completion directory exists and is in fpath
   mkdir -p ~/.zfunc
   pakyas completion zsh > ~/.zfunc/_pakyas

   # Add to ~/.zshrc if not already present:
   # fpath=(~/.zfunc $fpath)
   # autoload -Uz compinit && compinit
   ```

   ### Fish
   ```bash
   pakyas completion fish > ~/.config/fish/completions/pakyas.fish
   # Fish loads completions automatically
   ```

   ### PowerShell
   ```powershell
   pakyas completion powershell >> $PROFILE
   # Restart PowerShell
   ```

   ### Elvish
   ```bash
   pakyas completion elvish > ~/.config/elvish/lib/pakyas.elv
   # Add to ~/.config/elvish/rc.elv:
   # use pakyas
   ```

   - ## Verifying Installation section:
     After installation, type `pakyas ` and press Tab. You should see command suggestions.

   - ## See Also linking to CLI Overview (index.md)

Use :::tip noting Fish has the simplest setup (automatic loading).
Use :::note for Zsh users about running compinit after adding to fpath.
