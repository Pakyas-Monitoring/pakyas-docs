# Pakyas Documentation

Documentation for [Pakyas](https://pakyas.com) - cron job monitoring that tells you when your scheduled tasks fail, miss their schedule, or run too long.

## About Pakyas

Pakyas goes beyond simple up/down monitoring by tracking:
- Start, success, and failure status
- Exit codes and error output
- Runtime duration
- Schedule adherence

## Development

This documentation site is built with [Astro](https://astro.build) and [Starlight](https://starlight.astro.build).

### Prerequisites

- Node.js 18+
- npm

### Local Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```

The site will be available at `http://localhost:4321`.

### Build

```bash
npm run build
```
