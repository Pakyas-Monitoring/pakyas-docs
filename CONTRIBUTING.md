# Contributing to Pakyas Documentation

Thank you for your interest in improving the Pakyas documentation.

## How to Contribute

1. Fork this repository
2. Create a branch for your changes
3. Make your edits
4. Submit a pull request

## Local Development

```bash
npm install
npm run dev
```

## Documentation Structure

Documentation files are located in `src/content/docs/`. Each markdown file becomes a page on the site.

```
src/content/docs/
├── index.mdx           # Home page
├── getting-started.md  # Getting started guide
├── environments/       # CI/CD integration guides
├── api/                # API reference
└── ...
```

## Style Guidelines

- Use clear, concise language
- Include code examples where helpful
- Test any commands or code snippets before submitting
- Follow existing formatting conventions

## Questions

If you have questions about contributing, please open an issue.
